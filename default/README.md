# default

A minimal dev container: Ubuntu 22.04 (`mcr.microsoft.com/devcontainers/base:jammy`)
with zsh, Starship and the Claude Code VS Code extension. There is no project code
here. Use it as a template, or as an empty sandbox for trying out Claude Code.

To install your own project when the container is created, uncomment the relevant
lines in [.devcontainer/setup.sh](.devcontainer/setup.sh).
